TypeScript giúp bạn viết test code ít bug hơn nhờ kiểm tra kiểu dữ liệu ngay từ lúc code. Với QA học automation, đây là lợi thế lớn khi làm việc với API response, test data và Page Object.

Bash setup

type TestStatus = "passed" | "failed" | "blocked";

const tcId: string = "TC-001";
const retryCount: number = 2;

Nếu học TypeScript để làm automation mà tắt strict, bạn sẽ mất đi nửa giá trị của ngôn ngữ này. Rất nhiều bug trong test data, API response hoặc helper function sẽ bị bỏ sót đến lúc runtime. Project mới nên bật ngay từ đầu, còn project cũ có thể bật từng rule để sửa dần.

{
  "scripts": {

    "test:headed": "playwright test --headed"
  }
}
TypeScript strict-errors.ts 
type Product = {
  sku: string;
  name: string;
  status: "ACTIVE" | "INACTIVE";
};

const products: Product[] = [
  { sku: "SKU001", name: "Mouse", status: "ACTIVE" },
];

function findProduct(sku: string): Product | undefined {
  return products.find((product) => product.sku === sku);
}

const product = findProduct("SKU999");

if (!product) {
  throw new Error("Product not found");
}

console.log(product.name);
JSON tsconfig-step-by-step.json 
{
  "compilerOptions": {
    "strict": false,
    "noImplicitAny": true,

⚠️
Dấu hiệu nên bật strict ngay: helper nhận object nhưng không rõ shape, API response bị truy cập sai field, hoặc test data thiếu key mà code vẫn compile.
💡
strict của TypeScript khác với lỗi Strict mode violation của Playwright. TypeScript strict bắt lỗi type khi code; Playwright strict locator bắt lỗi khi một locator match nhiều element trên UI.

Variables, String, Number, Boolean Chi Tiết
let/const · template string · parse money · condition · assertion mindset
▼
Lý thuyết chi tiết

const dùng cho giá trị không gán lại như username, warehouse code, order code. let dùng cho trạng thái có thể thay đổi như retry count hoặc order status. String dùng cho URL, locator text, SKU, token, message. Number dùng cho quantity, price, total, status code. Boolean dùng cho điều kiện đúng/sai.

TypeScript primitive-automation.ts 
const warehouseCode: string = "W103";
const orderCode = `AUTO_ORDER_${Date.now()}`;
let orderStatus: "New" | "Approved" = "New";

orderStatus = "Approved";

function parseMoney(text: string): number {
  return Number(text.replaceAll(",", "").trim());
}

function canApproveOrder(status: string): boolean {
  return status === "New";
}

console.log(orderCode);
console.log(parseMoney("1,250,000"));
console.log(canApproveOrder(orderStatus));
⚠️
Dữ liệu lấy từ UI thường là string. Muốn so sánh với number thì convert rõ ràng bằng Number() sau khi clean dấu phẩy/khoảng trắng.

Array Và Object Cho Test Data/API
find · filter · map · some · every · reduce · nested object · spread
▼
Lý thuyết chi tiết

Array xuất hiện trong item order, serial, table rows và API response. Object là hình dạng chính của test data và request body. Cần chắc find, filter, map, some, every, reduce, nested object, destructuring và spread.

TypeScript array-object-order.ts 
type Product = {
  sku: string;
  name: string;
  price: number;
  status: "ACTIVE" | "INACTIVE";
};

const products: Product[] = [
  { sku: "SKU001", name: "Mouse", price: 100000, status: "ACTIVE" },
  { sku: "SKU002", name: "Keyboard", price: 250000, status: "ACTIVE" },
  { sku: "SKU003", name: "Monitor", price: 2500000, status: "INACTIVE" },
];

const product = products.find((item) => item.sku === "SKU002");
if (!product) throw new Error("Product not found");

const activeSkus = products
  .filter((item) => item.status === "ACTIVE")
  .map((item) => item.sku);

const totalPrice = products.reduce((total, item) => total + item.price, 0);

const baseOrder = {
  customerCode: "C001",
  warehouseCode: "W103",
  items: [{ sku: product.sku, quantity: 1 }],
};

const orderForW104 = { ...baseOrder, warehouseCode: "W104" };
⚠️
find() có thể trả về undefined. Luôn check trước khi đọc field, nhất là khi dùng dữ liệu từ API hoặc file test data.

interface LoginUser {
  username: string;
  password: string;
  role?: "admin" | "standard";

const users: LoginUser[] = [
  { username: "standard_user", password: "secret_sauce" },
  { username: "admin_user", password: "secret_sauce", role: "admin" },
];

function getAdminUsers(items: LoginUser[]) {
  return items.filter((user) => user.role === "admin");
}

Function, Async/Await, Promise Và Try/Catch
helper function · return type · missing await · API response handling · error log
▼
Lý thuyết chi tiết

Playwright gần như dùng async/await ở mọi action. Function giúp tái sử dụng logic tạo data, tính toán expected result, parse UI text hoặc gọi API. try/catch nên dùng khi cần log lỗi rõ hơn rồi throw lại để test fail đúng.

TypeScript helpers-and-api.ts 
type ApiResponse = {
  status: number;
  message: string;
};

function generateCode(prefix: string): string {
  return `${prefix}_${Date.now()}`;
}

function calculateTotal(items: { quantity: number; price: number }[]): number {
  return items.reduce((total, item) => total + item.quantity * item.price, 0);
}

async function fakeCreateOrder(): Promise {
  return { status: 200, message: "success" };
}

async function main() {
  try {
    const response = await fakeCreateOrder();
    if (response.status !== 200) throw new Error(response.message);
  } catch (error) {
    console.error("Create order failed:", error);
    throw error;
  }
}
⚠️
Lỗi rất thường gặp là thiếu await: action chưa chạy xong nhưng test đã đi tiếp, dẫn tới fail khó đoán hoặc flaky.

Generic, Type Narrowing, JSON, Null/Undefined
generic helper · unknown vs any · optional chaining · nullish coalescing · JSON parse
▼
Lý thuyết chi tiết

Các phần này không cần quá sâu lúc đầu, nhưng nên biết để đọc framework. Generic giúp helper dùng lại cho nhiều kiểu dữ liệu. Type narrowing giúp xử lý dữ liệu chưa rõ kiểu. Optional chaining và nullish coalescing giúp đọc optional data an toàn hơn.

TypeScript safe-data.ts 
function getFirstItem<T>(items: T[]): T | undefined {
  return items[0];
}

function printValue(value: string | number) {
  if (typeof value === "string") {
    console.log(value.toUpperCase());
  } else {
    console.log(value.toFixed(2));
  }
}

const raw = '{"message":"success","data":{"orderCode":"O001"}}';
const body = JSON.parse(raw) as {
  message: string;
  data?: { orderCode?: string };
};

const orderCode = body.data?.orderCode ?? "NO_ORDER_CODE";
console.log(orderCode);
⚠️
Hạn chế any vì nó tắt kiểm tra kiểu. Nếu dữ liệu chưa rõ, dùng unknown hoặc type rõ cho response rồi narrowing trước khi xử lý.
