Typed Page Objects, Components, Locator Ownership

▼
Lý thuyết

TypeScript rất hợp với POM vì method signature và object shape rõ ràng. Bạn có thể trả về page object tiếp theo sau action để test flow đọc như business steps.

TypeScript pages/LoginPage.ts 
export class LoginPage {
  constructor(private page: Page) {}

  async goto() {
    await this.page.goto("/");
  }

  async login(username: string, password: string) {
    await this.page.locator("#user-name").fill(username);
    await this.page.locator("#password").fill(password);
    await this.page.locator("#login-button").click();
  }
}

Trong dự án thật, không nên login lại ở từng test nếu flow không cần kiểm tra login. Hãy lưu session bằng storageState, tạo test data động để tránh trùng khi chạy parallel, và đọc credential từ environment thay vì hardcode.

TypeScript ui-api-flow.spec.ts 
test("approve order created by API", async ({ page, request }) => {
  const createRes = await request.post("/api/orders", {
    data: { customerCode: "C001", warehouseCode: "W103" },
  });
  expect(createRes.status()).toBe(200);
  const order = await createRes.json();

  await page.goto("/orders");
  await page.getByPlaceholder("Search order").fill(order.code);
  await page.getByRole("button", { name: "Search" }).click();
  await page.locator("tr", { hasText: order.code }).getByRole("button", { name: "Approve" }).click();

  const detailRes = await request.get(`/api/orders/${order.id}`);
  expect((await detailRes.json()).status).toBe("Approved");
});

Tuần 12 · Best Practices
🏆
Stable Tests, Typed Fixtures, Clean Project Structure
anti-flaky · deterministic data · maintainable suite
▼
Lý thuyết
❌
Tránh hardcode selector dễ vỡ, dùng waitForTimeout bừa bãi, để test phụ thuộc nhau, và nhét business logic vào spec file.
✅
Ưu tiên fixture typed, test data có ownership rõ ràng, page object nhỏ gọn, và helper nào cũng nên có tên phản ánh business action.
TypeScript fixtures/index.ts 
import { test as base } from "@playwright/test";
import { LoginPage } from "../pages/LoginPage";

type Fixtures = {
  loginPage: LoginPage;
};

export const test = base.extend<Fixtures>({
  loginPage: async ({ page }, use) => {
    await use(new LoginPage(page));
  },
});
